## Prompts

# Prompt 1: Generate the Design
```text
Generate a modern, premium landing page design for a fictional SaaS called **"Clarity"**.

I want it to look like a real 2026 startup website — clean, polished, modern, creative, and visually impressive.

Focus on a strong hero section with beautiful typography, bold messaging, abstract background graphics, geometric shapes, subtle gradients, floating elements, smooth visual transitions, and interesting decorative details.

Do **not** use dashboards, admin panels, analytics screens, or large product UI screenshots anywhere in the design.

Instead, make the website feel visually rich through creative background graphics, abstract illustrations, typography, icons, subtle animations, cards, shapes, and modern section transitions.

Include sections for features, benefits, testimonials, pricing, and a final CTA, but keep each section visually unique and engaging.

Keep the overall design minimal and professional with a distinctive visual identity. Avoid generic AI-generated website aesthetics, excessive glassmorphism, and overly complicated layouts.

Make **Clarity** feel like a premium startup that could realistically launch this website in 2026.
```

# Prompt 2: Build the Plan
```text
I already have a Laravel project using Vue + Inertia + Tailwind CSS.

Using the attached image as the design reference, create a complete plan for building this Clarity SaaS landing page.

Analyze the design and give me a practical implementation plan for the whole website, including:

page sections
Vue component structure
layout and responsive behavior
colors and typography
reusable components
animations and interactions
dashboard/product UI shown in the design
icons and assets
mobile version
Tailwind implementation approach
recommended development order
I want the final website to closely match the reference image while still being clean, responsive, and production-quality.

Don't write the code yet. Just give me the complete plan and structure I should follow to build the website in my existing Laravel + Vue + Inertia project.
```
